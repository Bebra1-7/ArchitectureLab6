#Контрольные вопросы 

##1. Чем файл программы на HDD/SSD отличается от работающего процесса?  
- На ССД хранится сам код, а в работающем процессе поступа.т команды для процессора

##2. Зачем программе нужна оперативная память после запуска?
- Чтобы хранить команды для процессора

##3. Как по Диспетчеру задач можно увидеть, что программа действительно работает?  
- Увел. нагрузка на процессор и потребление опер. памяти

##4. Почему во время вычислений увеличивается загрузка CPU?  
- Потому что, процессору надо выполнять команды которые ему даются

##5. Остаётся ли файл программы на HDD/SSD после завершения процесса? 
- Остаётся, не остаются лишь команды для процессора

#Итоговый вывод
- SSD тут хранятся данные, которые потом преобразуются в команды для процессора
- RAM в нём хранятся временные команды для процессора
- процесс в нём есть команды для процессора
- CPU в нём выполняются команды
